# Dicky's Board Game Library

A searchable catalogue of 76 owned game entries, with cover pictures, practical categories, descriptions, dated BoardGameGeek ratings and attributed community-review summaries.

Open `index.html`, or visit the GitHub Pages site. Search and filter by category or player count, then print the selection as a PDF. The downloadable HTML and full PDF can also be shared offline.

Ratings and reviews were researched on 13–14 October 2026. Unverified information and edition differences are labelled. Community-review summaries represent individual contributors, not an editorial verdict from BoardGameGeek.

Cover artwork belongs to its respective rights holders. Each pictured entry links to its public image source; images identify the games in this personal collection. No affiliation with BoardGameGeek or the publishers is implied.

The site has no accounts, analytics or server-side storage. Images are bundled; external links open only when selected.
